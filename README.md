# ClusterBoard

Адаптивный портал для управления людьми и командами, квартальными целями и важными инициативами. Текущая версия — **0.9**.

- Структура кластера, распределение сотрудников, продукты и владельцы.
- Общие цели, ответственные, исполнители и прогресс.
- Реестр инициатив, доска статусов и режим презентации.

## Запуск

Откройте `public/index.html` в браузере или разместите его на статическом хостинге. Сборка и внешние библиотеки не нужны.

Для существующей серверной конфигурации: `docker compose up -d`. Требуются Docker Compose и внешняя сеть `proxy`; страница доступна на `http://127.0.0.1:8081`. `clusterboard.conf` содержит конфигурацию проксирования для Nginx Proxy Manager.

Развёрнутый портал: [ClusterBoard](http://176.123.167.199/?v=0.9#/initiatives/registry).

## Данные

Данные сохраняются в `localStorage` текущего браузера. Серверной базы, авторизации и синхронизации устройств нет. Для резервного копирования и переноса используйте экспорт/импорт JSON. Демопримеры инициатив добавляются через интерфейс.

Подробности версии — в [документации](docs/clusterboard_v0.9.md). Поставляемый отчёт проверок — `test_report.json`.
